# 範例：斷劍騎士莉瑟爾 ＋ 艾瑞斯塔王國（西方奇幻）

依 CLAUDE.md §4.2／§4.3 的寫卡守則（PLists + Ali:Chat、世界書進階用法）製作的自製範例，可自由使用、修改。

| 檔案 | 內容 |
| --- | --- |
| `斷劍騎士莉瑟爾.png` | 角色卡（PNG，內嵌 JSON 與世界書），可直接匯入 Tavern 或 SillyTavern |
| `斷劍騎士莉瑟爾.json` | 同一張角色卡的 JSON 版本 |
| `艾瑞斯塔王國-世界書.json` | 世界書（SillyTavern World Info 格式），也可單獨匯入 |

在網頁上也可以直接按「角色」或「世界書」頁的 **加入西幻範例**。

## 這張卡示範了什麼

**角色卡**
- **描述欄**只放兩段 Ali:Chat 對話（生平簡介、喜歡和討厭什麼）：{{user}} 簡短提問，{{char}} 用說話方式、動作與經歷展現個性。
- **PList** 放在角色備註（`extensions.depth_prompt`，深度 4），類別依重要性排列：身體 → 衣服 → 標籤 → 場景 → 性格（最重要的放最後）。
- **第一條訊息**很長、整段不換行：交代場景、外貌、說話方式與和 {{user}} 的關係，且不替 {{user}} 行動。
- 個性摘要、情境欄留空（寫在 PList 裡）；對話範例欄留空（Ali:Chat 在描述欄，永久保留）。

**世界書**
| 技巧 | 條目 |
| --- | --- |
| 影響小的背景放「角色設定之前」 | 艾瑞斯塔王國概述、二十年前的龍災 |
| 地點與勢力放「角色設定之後」，依插入順序排列 | 霧橋鎮、斷劍酒館、餘燼騎士團… |
| AND／NOT 互補條目 | 「王冠」＋失竊 → 失竊的晨曦王冠（AND，作者備註之前）；「王冠」但沒提失竊 → 王冠的傳說（NOT） |
| 觸發機率 | 霧夜異聞（30%） |
| 遞迴觸發 | 灰燼森林的內容提到「月精靈」「龍災」，會連帶觸發；背景條目關閉「內容不會觸發其他條目」避免連鎖 |
| 常駐 ＋ 指定深度（效果等同作者備註） | 敘事基調（常駐 @4） |
