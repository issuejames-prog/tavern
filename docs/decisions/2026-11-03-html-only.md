# 2026-11-03 只保留網頁版，刪除自架伺服器版

## 決定

專案改為**完全在瀏覽器執行的網頁**（GitHub Pages），刪除 `server/`（Hono + SQLite）、登入頁、`.env` 與相關腳本。
之後所有功能都以「打開網址就能用」為前提開發。

## 原因

- 使用者以 GitHub Pages 上的瀏覽器模式完成階段一驗收，並表示之後都以 HTML 為主軸。
- 兩套執行模式（伺服器／瀏覽器）讓每個功能都要寫兩次、測兩次，違反「自用優先、架構簡單」原則。
- 在 Windows 本機安裝伺服器版需要處理 Node 版本、原生模組、`.env` 等問題，且曾因此把 `.env` 誤傳到公開 repo。

## 影響

- 資料由 SQLite 改為瀏覽器 IndexedDB，提供全部資料的匯出／還原備份；階段一存在 localStorage 的資料自動搬移。
- 金鑰只存在使用者瀏覽器（延續 `2026-11-03-browser-mode.md` 的防護：CSP、只連 OpenRouter、備份不含金鑰）。
- 路線圖中依賴伺服器的項目（例如 Docker／Caddy 部署、伺服器端每日上限）移除；跨裝置同步改列為階段四的選配項目（使用者自選雲端）。
- CI 簡化為型別檢查、`shared/` 單元測試、建置；Windows／Node 原生模組相容測試不再需要。
